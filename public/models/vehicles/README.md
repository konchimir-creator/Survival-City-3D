# Vehicle GLB Models

## sports_car.glb
- Источник: предоставлена пользователем (генератор tripo3d.ai), загружена в ветку `main` как `sports_car.glb`
- Оригинал: 490 318 треугольников, 14.8 МБ, текстуры 2048x2048 JPEG
- Оптимизация (gltf-transform `optimize`): weld + simplify (error 0.0005) + текстуры 1024 WebP + quantize → **~33.5k треугольников, 842 KB**
- Оси в файле: длина вдоль X, нос (перед) = +X, спойлер (зад) = -X, Y-вверх, центр меша в origin, низ колёс y = -0.148
- В игре (`GLBCar.tsx`): поворот -90° (нос в +Z), масштаб 4.3 (длина 4.3 м, ширина ~2.4 м, высота ~1.27 м), колёса на земле
- Меш цельный (колёса запечены) — вращение колёс отключено; кузов белый → цвет задаётся тинтом материала
- Применяется к типам sedan / taxi / police; van остаётся процедурным
- Фолбэк: при 404/битом файле — процедурная машина (VehicleErrorBoundary + Suspense)

## Проверка
- Машины едут носом вперёд (корма со спойлером сзади)
- Ночью загораются фары/стопы
- taxi: жёлтый + шашечки; police: белый + мигалки
- LOW graphics: 3 машины, ~100k tris суммарно
