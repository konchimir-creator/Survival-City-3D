# Survival City 3D

Браузерная 3D survival/life/economic RPG от третьего лица.

## Технологии
- Next.js 14 + React 18 + TypeScript
- Three.js + @react-three/fiber + @react-three/drei
- @react-three/rapier (физика)
- Zustand (состояние)
- Tailwind CSS

## Запуск
```bash
npm install
npm run dev
```
Открой http://localhost:3000

## Управление
- WASD — движение
- Shift — бег
- Мышь — камера (клик для захвата)
- Колесо — зум
- E — взаимодействие
- I — инвентарь
- C — персонаж
- M — карта
- Esc — меню

## Геймплей (Vertical Slice)
- 3D персонаж (временный stylized placeholder из примитивов, финальная GLB модель в разработке)
- Third-person камера с коллизией
- Квартал 300x300м: дороги, тротуары, 12 зданий
- Магазин с интерьером и экономикой
- 3 работы (грузчик с задачей переноса коробок, кафе, уборщик)
- Ночлежка (сон)
- Потребности: здоровье, голод, жажда, энергия, гигиена, настроение, стресс
- Экономика: наличные, банк, долги
- Инвентарь и экипировка
- Время: день/ночь с динамическим освещением
- Погода: ясно/облачно/дождь с частицами и мокрым асфальтом
- 10-20 NPC с маршрутами
- Трафик: седан, такси, фургон, полиция
- Сохранения в localStorage с версионированием
- Настройки графики LOW/MEDIUM/HIGH
- Миникарта

## Статус модели персонажа
Текущая модель — качественный low-poly stylized humanoid, собранный из примитивов программно (капсулы, сферы) с материалами (тёмное худи, джинсы, кроссовки, рюкзак) и анимациями Idle/Walk/Run через процедурную анимацию. Это **временный placeholder** согласно ТЗ. Архитектура готова для замены на GLB/GLTF с AnimationMixer/useAnimations без изменения логики.

## Известные ограничения
- Модель персонажа — placeholder (нужна финальная GLB)
- Интерьер только у магазина, остальные здания — экстерьер
- Звук — система подготовлена, ассеты placeholder
- Физика бордюров — упрощена, чтобы не блокировать
- Тени оптимизированы, но на слабых устройствах LOW рекомендован
